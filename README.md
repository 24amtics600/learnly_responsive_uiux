# Learnly – Responsive EdTech Landing Page

## Project Overview
Learnly is a fictional online learning platform designed to help college students develop practical skills through structured courses and personalized learning experiences.

This project was created as part of an individual UI/UX design assignment using Figma.

## Target Audience
College students and young professionals aged 18–25 interested in developing technical skills and improving their career opportunities.

## Website Pages
1. Home – Platform introduction, hero section, features and statistics.
2. Courses – Course listings, categories and search interface.
3. About – Platform mission, vision and team introduction.
4. Contact – Contact form, support information and FAQs.

## Design Features
- Responsive desktop, tablet and mobile layouts.
- Consistent navigation and footer.
- Reusable UI components.
- Figma Auto Layout.
- Shared color and typography styles.
- Consistent spacing and visual hierarchy.
